# Dependencies and reference material

NESRecomp is fetched separately at the revision recorded in `dependencies.json`. Its PolyForm Noncommercial license and all bundled third-party notices continue to apply. The integration's MIT license does not change those terms. SDL2 and the optional TriCNES test oracle have their own licenses in their respective upstream distributions. Check the complete dependency tree before packaging.

LuigiBlood's Balloon Fight disassembly is a reference for cartridge layout, named routines and debugging. No source from that repository is included here. Permission would need to be established before copying its material.

Original ROM data, graphics and audio are user inputs. Local generated C and executables may embody translated game code; excluding a `.nes` file alone is not enough to make an artifact suitable for public distribution. Public release packaging remains a separate milestone.
